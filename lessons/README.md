# Lessons

One file per hard-won lesson, named `YYYY-MM-DD-<slug>.md`, written in project-neutral words
(what class of failure, what caught it, what rule follows). A lesson that repeats across two
projects is a retrospective candidate for a forged skill; that is crux `retrospective`'s job,
and it reads this directory.

Shape:

```
# <one-line rule>
Observed: <project-neutral description of the incident class>
Caught by: <which gate or discipline>
Rule: <the one thing to do differently>
Evidence: <receipt/log path in the consuming project, optional>
```
