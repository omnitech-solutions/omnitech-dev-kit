# Objectives

The ruler every kit proposal is measured against. Change by superseding a line, not editing it.

1. A unit of work is a bounded packet with an exclusive file set, executed in an isolated
   worktree, verified by a separate run that re-runs the declared bar, and accepted by a human
   at the live boundary. Model verdicts are claims until that gate passes.
2. Every paid run has a wall-clock cap, a tool allow-list, no session persistence, a dollar
   guard, and a spend row. No run is started by a loop.
3. Evidence about which disciplines pay off accumulates in one place across all projects, in
   crux's forge-log format, so the retrospective can mine it.
4. The kit stays a companion to crux: nothing here duplicates a crux skill, and the kit
   survives crux upgrades unchanged (see `COMPAT.md`).
5. Nothing project-specific lives here. Projects keep their ledger, fixtures, packets,
   receipts, and spend; the kit keeps shapes, disciplines, and lessons in project-neutral words.
